Preguntas frecuentes

Claro desde el principio.

Lo que conviene saber antes de usar NotaPro.

¿Mis notas se guardan automáticamente?

Sí. Se guardan en el almacenamiento local de este navegador. No se envían a un servidor desde esta versión.

¿Los 20 TB son almacenamiento real?

No. Es una cuota de referencia visual. Para tener almacenamiento en la nube de esa capacidad se necesita contratar o conectar un proveedor y configurar un backend seguro.

¿Puedo usar mis notas en otro dispositivo?

Puedes exportar una copia JSON e importarla en otro dispositivo. La sincronización automática entre dispositivos no está incluida en esta versión local.

¿Puedo guardar una nota como PDF?

Sí. Abre una nota, utiliza Imprimir / PDF y elige “Guardar como PDF” en el diálogo de impresión del navegador.

Nota sobre la capacidad real

Esta aplicación funciona localmente. No puede reservar 20 TB en tu dispositivo ni sincronizar automáticamente entre equipos. Para ello se necesita un backend seguro y un proveedor de almacenamiento en la nube.

Desglose por documento

El tamaño incluye el texto, el título y los metadatos serializados; una nota sin contenido puede tener algunos bytes de metadatos aunque su contenido sea 0 B.
